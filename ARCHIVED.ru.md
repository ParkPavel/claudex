# Клаудекс ушёл в борщ

[English](ARCHIVED.md) · **Русский**

> **Статус: ARCHIVED** · 2026-10-07 · версия 1.1.0 — последняя.
> Продолжение — **[Borshkit (Борщкит)](https://github.com/ParkPavel/borshkit)**.

Клаудекс был хорошим куском мяса. Его довели до нужной
[степени прожарки](https://en.wikipedia.org/wiki/Doneness), дали ему пройти
[реакцию Майяра](https://ru.wikipedia.org/wiki/Реакция_Майяра) до корочки и опустили в кастрюлю.
Теперь он — ингредиент [борща](https://ru.wikipedia.org/wiki/Борщ), который варится в проекте
[Borshkit](https://github.com/ParkPavel/borshkit). Отдельным блюдом мясо больше не подают.

---

## Ревью причин архивации

Оформлено так, как Клаудекс сам принимал работу: каждое утверждение — критерий, у каждого
критерия — вердикт и улика. Что не показано, остаётся `UNKNOWN` и не становится `PASS` по
умолчанию. Даже на собственных похоронах.

```text
$ claudex task converge archive-claudex
```

| # | Критерий | Вердикт | Улика |
|---|---|---|---|
| 1 | Мясо прожарено: идеи проверены в деле, а не на салфетке | `PASS` | 1.0.0 прошёл семь перекрёстных раундов ревью, последний — без P1 и P2; за плечами журнал на 202 задания ([CHANGELOG](CHANGELOG.md)) |
| 2 | Мясо отдало бульону всё лучшее | `PASS` | Контракты задач, улики на снимке, ревью другим исполнителем и честное «не проверено» живут в Borshkit — см. [рецептуру](#что-куда-ушло) |
| 3 | Две кастрюли с одним рецептом на одной плите не нужны | `PASS` | Поддерживать два харнесса с одной идеей — значит дважды солить и дважды пересаливать |
| 4 | Имя стало тесным | `PASS` | «Claude + Codex» — это про двух поваров. Борщ варят любые агенты в любом проекте: веб, плагин, библиотека, мобильное приложение, исследование |
| 5 | Проект закрыт, потому что не сработал | `FAIL` | Сработал. Закрыт, потому что пригодился — мясо не выбрасывают, его едят |
| 6 | Кому-то нужен Клаудекс в чистом виде | `UNKNOWN` | Улик нет. Если вы такой человек — код под Apache-2.0, форк никто не запрещает |

**Итог:** архивация обоснована по всем проверяемым критериям; критерий 5 опровергнут уликой,
критерий 6 честно оставлен `UNKNOWN`. Мясо готово, кастрюля ждёт.

## Что куда ушло

Рецептура по [README Borshkit](https://github.com/ParkPavel/borshkit#readme) на момент
архивации (0.11.1). Повар оставляет за собой право менять рецепт — сверяйтесь с кастрюлей.

| Было в Клаудексе | Стало в борще |
|---|---|
| `task init` · `task check` · `task converge` — контракт и вердикт по каждому критерию | Цель и критерии задачи, лист приёмки |
| Улики, привязанные к дайджестам исходников, конфигурации и спецификации | Каждое доказательство привязано к точному состоянию файлов |
| Ревью моделью другого провайдера, только на чтение | Ревью другим исполнителем |
| `UNKNOWN` никогда не становится `PASS` | Что не проверено, так и называется: **не проверено** |
| Отдельный `worktree` на каждого пишущего | Агент работает в своей копии проекта |
| Хуки Claude Code (`claudex hook …`) | Плагин Claude Code с защитными хуками |

## Как переехать

```text
/plugin marketplace add ParkPavel/borshkit
/plugin install borshkit@borshkit
```

Или командой в терминале:

```sh
git clone https://github.com/ParkPavel/borshkit.git
cd borshkit && npm link        # появятся команды borshkit и borsch
```

Этот репозиторий ничего не обещает про перенос локального состояния Клаудекса (`.claudex`,
журналов заданий, контрактов). Что Borshkit умеет забрать с собой — смотрите в его документации.
